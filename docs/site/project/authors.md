# Authors

## Original StripTool

- **Janet Anderson (APS)** wrote the early stripTool program.
- **Christopher A. Larrieu (TJNAF)** primarily designed and wrote the later StripTool program.
- **Albert Kagarmanov (DESY)** added Y-axis zoom and auto-scaling, current values in the legend, logarithmic scaling, and archived-data history.
- **Kenneth Evans, Jr. (APS)** merged the TJNAF and DESY versions in 2002, maintained the unified program, and wrote the historical user guide.

## Qt StripTool

- **Robert Soliday (APS)** developed and maintains the Qt port.
